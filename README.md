# demo.ckan.org -- removed from the catalog

This repository used to profile demo.ckan.org as a data provider. It is the public demo site of the CKAN
open-source catalogue software, with a handful of sample datasets; it publishes no one's data.

It was removed on 2026-09-24 as a catalog-hygiene decision by API Evangelist (roadmap#684). Nobody asked.

The slug and the demo host are on the delisting registry (api-search/network/_data/delisted.yml), so
harvests will not re-add this record. ckan.org and real CKAN portals are not on the registry.
Questions: info@apis.io.
